# Fullstack-Dev-Labs

My work through the freeCodeCamp Full Stack Developer curriculum: labs, workshops, small projects and notes, one lesson at a time.

## Why this repo exists

I already build things with React, Next.js and Node. This is me going back to the basics because there is a difference between knowing how to make something work and knowing why it works. This repo is me going back for it, properly this time.

## What you will find here

- **Labs**: the hands-on builds from each section of the curriculum with the task that was assigned.
- **Notes**: short write-ups of the ideas that actually stuck, like why every input needs a label, or why a table needs a caption and `scope` on its headers

## Structure

```
Fullstack-Dev-Labs/
├── 01-html/
├── 02-css/
├── 03-javascript/
├── 04-front-end-libraries/
├── 05-back-end/
├── 06-databases/
└── notes/
```

Each folder holds the labs for that section. Each lab has its own folder with the code and a short README covering what it is, what I learned and anything that tripped me up.

## Tech covered

HTML, CSS, JavaScript, React, Node.js, Express, databases, and accessibility throughout.

## How to run a lab

Most of the early labs are plain HTML, CSS and JavaScript. Open the `index.html` file in a browser and you are good to go.

For the later labs that need a server or dependencies:

```bash
cd folder-name
npm install
npm start
```

Each lab's README says exactly what it needs.
