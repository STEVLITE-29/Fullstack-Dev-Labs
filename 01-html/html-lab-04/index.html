The Web Trio: HTML, CSS & JavaScript

Every website you've ever visited is built on three core languages. HTML gives a page its structure, CSS makes it look good, and JavaScript brings it to life. Here are three quick videos that explain each one in about two minutes.

HTML: The Skeleton

HTML defines the structure of a web page. It controls the headings, paragraphs, links and everything else you see on the screen. Watch this quick intro to learn how it works.

CSS: The Style

CSS is the language that makes websites look beautiful. Learn how it handles colours, spacing and layout, and why every element on a page is really just a box.

JavaScript: The Brain

JavaScript adds interactivity to the web. It powers button clicks, live updates, and even servers through Node.js. Here's the whole language in a nutshell.
